## Overview

A multi-agent content production system for e-commerce sellers. Simply enter a product title and category, and the system generates an optimized title, key selling points, detailed product descriptions, SEO keywords, social media copy, a four-dimensional quality score, plus product images and short videos — all in one click.

> **Example**: Input "Wireless Bluetooth Earbuds + 3C Digital" → Output "[ANC Noise Cancelling] TWS Pro Wireless Earbuds, 30H Battery Life, IPX5 Waterproof" title + 5 selling points + product description + 8 SEO keywords + social media copy + 4.05/5 quality score + product image + 15-second video.

Under the hood, 8 specialized Agents form a pipeline: Product Understanding → Copywriting → SEO Optimization → Compliance Review → Quality Scoring → Auto-Rewrite → Image Generation → Video Generation. The text pipeline supports Mock, vLLM, Transformers + LoRA, and OpenAI-compatible API backends. The visual pipeline integrates Seedream and Seedance clients with Mock fallback.

> Current Status: Full Mock text pipeline verified. Image and video pipelines produce real API outputs (see Showcase below). Qwen3-8B QLoRA configuration and scripts are ready; training results are pending.

### Key Features

- **Agent Feedback Loop**: Generate → Score → Rewrite → Re-score. Low-quality content is automatically optimized for up to N rounds
- **Image Generation**: Platform-specific image prompts with real Seedream API outputs (see `docs/showcase/`)
- **Video Generation**: Platform-specific video prompts with real Seedance API outputs (see `docs/showcase/`)
- **Fine-tuned Model Integration**: Load LoRA adapters via Transformers or vLLM; current training targets Qwen3-8B
- **Multi-Platform Support**: Four platform styles — Taobao, Amazon, Douyin (TikTok China), Xiaohongshu — each with distinct templates and tone
- **4D Quality Evaluation**: LLM-as-Judge (Accuracy / Attractiveness / Compliance / SEO) + ROUGE-L + deterministic metrics
- **Three-Way Comparison**: base model vs fine-tuned vs fine-tuned+rewrite, quantifying the value of fine-tuning and the rewrite loop
- **Containerized Deployment**: Docker / Docker Compose for Mock API, with optional `vllm` and `full` profiles
- **Privacy & Security**: All API keys and model paths managed via `.env` file, excluded from version control

## Getting Started

### Prerequisites

- Python 3.10+
- (Optional) CUDA 12.1+ / NVIDIA GPU for model inference and training
- (Optional) Docker for containerized deployment

### 1. Install Dependencies

```powershell
# Install runtime dependencies
pip install -r requirements.txt

# Full install (including training dependencies)
pip install torch transformers datasets accelerate peft bitsandbytes vllm
```

### 2. Configure Environment

```powershell
# Create .env from template
copy .env.example .env

# Edit .env to add your API keys (if using external APIs)
# Default Mock mode works without any modifications
```

### 3. Verify Full Mock Pipeline (No GPU Required)

```powershell
python quick_start.py

# Text-only pipeline
python quick_start.py --no-image --no-video

# Use custom product list
python quick_start.py --product examples/sample_products.json
```

### 4. Start API Server

```powershell
# Mock mode (default)
python -m uvicorn src.api.server:app --port 8888

# Or run directly (reads .env config)
python src/api/server.py
```

### 5. Docker Deployment

```bash
# Build and start (Mock mode)
docker-compose up -d

# Start vLLM inference + API (requires NVIDIA GPU; adjust model and LoRA paths first)
docker-compose --profile vllm --profile full up -d
```

## Compliance & Quality Assurance

### Ad Law Compliance

The system includes deterministic rule detection for **13+ advertising law prohibited terms**, covering:

- **Absolute claims**: "best", "#1", "top-tier", "ultimate", "one-of-a-kind", "universal", "national-level"
- **False advertising**: "permanent", "100%", "all-natural", "no side effects"
- **Sensitive terms**: "cure", "eradicate"

Deterministic rules + LLM dual review. High-risk content is automatically routed to the rewrite pipeline.

### Four-Dimensional Quality Evaluation

| Dimension | Weight | Evaluation Criteria | Scoring |
|-----------|--------|---------------------|---------|
| Accuracy | 35% | Attribute values, specs, and brand consistency with source | 1-5; 5 = no fabricated info |
| Attractiveness | 30% | Language fluency, selling point prominence, purchase intent | 1-5; 5 = scenario-based descriptions |
| Compliance | 20% | Ad law prohibited terms, false advertising detection | 1-5; 5 = no violations |
| SEO Coverage | 15% | Keyword density, title structure, tag coverage | 1-5; 5 = core + long-tail keyword coverage |

**Quality Threshold**: Total score ≥ 3.5/5. Below threshold triggers automatic rewrite.

## Evaluation System

### Three-Way Comparison

| Dimension | Base Model | Fine-tuned | Fine-tuned + Rewrite |
|-----------|------------|------------|---------------------|
| Copy Quality | Generic style | E-commerce optimized | E-commerce optimized + auto-improved |
| SEO Coverage | Average | Targeted improvement | Best |
| Compliance | Potential violations | Learned e-commerce norms | Dual protection |
| Quantified Value | Baseline | Fine-tuning gain | Feedback loop gain |

### Evaluation Metrics

- **LLM-as-Judge**: 4D weighted scoring (Accuracy 35% / Attractiveness 30% / Compliance 20% / SEO 15%)
- **ROUGE-L**: LCS-based text similarity (supports jieba tokenization / character-level fallback)
- **Deterministic Metrics**: Length ratio, 2-gram repetition rate, start-end completeness
